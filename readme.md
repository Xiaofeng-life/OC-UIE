# OC-UIE

**Beyond Unidirectional: Unsupervised Trajectory Learning for Omnidirectional Controllable Underwater Image Enhancement**

## Introduction

This repository is the official implementation of OC-UIE, an unsupervised trajectory learning framework for omnidirectional controllable underwater image enhancement.

The source code will be publicly released in this repository once the paper is officially published online.
